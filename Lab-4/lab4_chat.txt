● I implemented sky_color in game.py. I ran it for a few wave numbers and it
  returns valid colors, but I haven't looked at it in the running game.

  - Wave 1: it returns None, so you get the default near-black sky.
  - Later waves: it returns an (r, g, b) tuple. The base color brightens by
    about 3 per channel for each wave, up to a cap of 30, so the yellow and red
    sprites and the white player stay readable.
  - Hue shift: each channel also drifts on its own sine wave, using the PHASES
    list that was already defined at the top of the file. The hue therefore
    changes from wave to wave and is different each run.
  - Clamping: values are clamped to 0–255.

  Sample output:

  ┌──────┬──────────────┐
  │ Wave │  Sky color   │
  ├──────┼──────────────┤
  │ 2    │ (10, 0, 7)   │
  ├──────┼──────────────┤
  │ 5    │ (50, 29, 66) │
  ├──────┼──────────────┤
  │ 10   │ (0, 24, 14)  │
  ├──────┼──────────────┤
  │ 50   │ (15, 62, 47) │
  └──────┴──────────────┘

  The sine swing is ±35, larger than the base color, so a channel can hit 0
  (wave 10 has red at 0). The sky stays dark everywhere, but shrink the 35 if
  you want it subtler.

● I implemented on_humanoid_rescued in game.py as a floating green "+500" popup.
  I checked it headlessly: the popup is created, drawn and expires after about
  a second. I haven't looked at it in the actual game window.

  - Hook: it adds a popup at the rescued humanoid's position, slightly above it.
    It only receives the humanoid, so the popup is kept in a new module-level
    list, RESCUE_POPUPS.
  - Game.update: each frame the popups drift upward and their remaining time
    counts down. Expired ones are removed.
  - Game.draw: each popup is drawn at its world position through screen_x, so it
    stays with the humanoid as the camera moves. It fades out over POPUP_LIFE
    (1 second).
  - Game.reset: it clears the list, so no popups carry over into a new game.

  I didn't add the invulnerability boost. The hook has no access to the player,
  so that would need either a global reference or a change to the call site in
  update(). Say if you want it.
